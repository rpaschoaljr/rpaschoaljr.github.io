# cv-online-angular

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 21.1.5.

## Como rodar o projeto localmente

1. Entre na pasta:
   ```bash
   cd cv-online-angular
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor:
   ```bash
   ng serve
   ```

4. Acesse: `http://localhost:4200` no seu navegador.

## Como fazer o Build (para produção)

Para gerar os arquivos finais que irão para o GitHub Pages:
```bash
ng build --base-href /rpaschoaljr.github.io/
```
Os arquivos serão gerados na pasta `dist/cv-online-angular/browser`.
